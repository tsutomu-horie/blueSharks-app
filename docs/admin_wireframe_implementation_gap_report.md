# 管理画面とワイヤーフレームの実装差分

作成日: 2026-09-07
対象ワイヤーフレーム: [BlueSharks 管理画面ワイヤーフレーム](https://docs.google.com/presentation/d/1dKK2x_yO8GSJfZQrLHO4j9G87r2sYJqv/edit)
照合対象: `blueSharks-server/bluesharks-develop` の管理画面実装

## 結論

会員、ポイント、QR施策、ランキング、景品、景品交換、監査ログの主要な一覧・操作画面は実装されています。一方、運用を画面だけで完結するために、ダッシュボードの実データ表示、会員取込の検証・履歴、育成ゲーム設定、ランキング公開承認などが残っています。

## 仕様確定後に修正が必要な差分

### ポイント取消

取消処理自体は実装されていますが、現在は取消可能な直近の `grant` / `spend` 取引を自動選択します。ワイヤーフレームの意図に合わせるには、台帳行を選択し、元取引に紐づけて全額リバーサルするUIが必要です。

### 二者承認

ポイント調整と景品交換取消は現在の管理画面では即時実行です。ワイヤーフレームの申請→承認→実行→監査フローを採用する場合、申請者と承認者を分ける画面・状態遷移が必要です。ランキング公開申請については承認APIがあるため、承認画面を追加すれば運用を完結できます。

### QRオフライン受付

ブラウザでのオフライン受付は未対応です。ただし、設計上は初期リリースをオンライン必須とする暫定方針があるため、現時点では仕様未確定事項として扱います。

### 景品画像

画像保存キーの入力とプレビューはありますが、管理画面から画像ファイルをアップロードする操作はありません。ファイルアップロードを必要とするか、事前に保存されたキーを利用するかの確定が必要です。

## 実装済みの主な範囲

- 会員検索、会員詳細、会員資格の基本表示
- ポイント残高、付与ロット表示、付与・減算・取消
- QR施策の作成・編集、イベント紐付け、QR読取履歴、カメラ読取
- ランキングの再集計、プレビュー、公開申請
- 景品の作成・編集、画像プレビュー、在庫・交換期間
- 景品交換の検索、受渡完了、取消
- 監査ログの検索・詳細表示
- 管理者一覧・追加・編集、権限による画面制御

## 優先順位案

1. ランキング公開申請の承認・却下画面
2. 会員資格取込の事前チェック、行別エラー、取込履歴
3. 育成ゲーム設定画面
4. ダッシュボードの実データ・要対応一覧
5. 会員詳細の台帳明細・操作履歴
6. QR取消・再付与とポイント取消対象選択
7. WordPress導線、管理者無効化、パスワード再設定導線

## 確認時点の制約

- 照合はソースコードとワイヤーフレームの内容に基づく静的確認です。本番環境での権限別操作や実データ表示は確認していません。
- ワイヤーフレーム内で「要確認」とされている承認方式、CSV/API仕様、監査ログ保存期間、PIIマスク・CSV出力権限は、正式仕様の確定が必要です。
