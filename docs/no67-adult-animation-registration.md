# No67 成体アニメーションの接地固定

原PNGを変更せず、フレーム共通の足・家具と動く上半身を分離する。掃除の箒で隠れた足は各体形の脚内縁に基づく軸で補完し、骨盤位置で胴体を配置する。旧外形中心は箒の遮蔽に影響され、復元軸として使えない。腰の局所接続は現在の胴体と固定脚から生成する。休養では第1コマの家具を保持し、人物だけを切り替える。Idleの足アンカー補正、休養完了時の家具高さも統一。

生成元は `tool/no67/generate_registration_layers.py`。開発環境のPillow/NumPyで実行後、生成Dartをdart formatする。入力のPNGは変更しない。CSVは元素材登録座標、JSONは骨盤青領域の実測登録差分。

回帰テストは `adult_frame_registration_test.dart`。足裏全幅で足色の変化を検出し、実際の箒色または足色との混色で遮蔽された場合だけ区別する。家具の画素固定も検査する。数値一致だけで目視合格としない。

PR/SH/WTB活動全6像、base/完了を含む12像を独立目視。GIFは650ms/コマの実装描画であり実ゲーム録画ではない。実ゲーム上の端末検証は別途必要。
