# No67 成体アニメーションの接地固定

原PNGを変更せず、成体BASE/PR/SH/WTBの表示位置を登録する。Idleは足アンカーを使用。育成ホームの非歩行待機も `TrainingHomeCharacterFrameSet` の透明余白正規化で同じ足アンカーを使い、ホーム専用描画経路で検証する。歩行の登録座標は変更しない。掃除・筋トレは人物全体を連続メッシュとして描画し、腰から足までの接続を保ちながら接地点を揃える。箒とダンベルは元画の輪郭を保持して別に描画する。固定脚の貼り合わせは使用しない。

掃除の箒で隠れた足は脚内縁の軸を使って復元する。BASE/SHでは足の範囲に限定して反対側の尾の混入を防ぎ、箒と足の混合境界色を透明な穴として消さない。足裏だけでなく甲の透明亀裂と孤立片も検査する。

仕事は動作2コマの人物の頭中心と机前縁を独立して固定する。PR第2コマの原画に欠けている黒い机上物は第1コマの既存画素で保持する。休養は第1コマの家具を固定し、人物のヒレを含む輪郭を保持する。内部の共通キャンバスへ登録した後で外側のalignmentを適用する。

生成元は `tool/no67/generate_registration_layers.py` と `generate_grounded_profiles.py`。Pillow/NumPyで実行し、生成Dartをdart formatする。PNG入力は変更しない。CSVは原画の登録座標を記録する。

描画準備は通常アニメーションと完了ポーズの両方で待機する。完了画像が準備できてから500msの表示時間を開始する。失敗時は単一の元画像へ戻し、失敗キャッシュを除去して再試行を可能にする。読み上げラベルを保持する。

`adult_frame_registration_test.dart` は全体形の描画、動作→完了の接地、甲の亀裂、尾片、家具・道具保持を検査する。`grounded_frame_initialization_test.dart` は画像準備の初回表示、失敗再試行、読み上げを検査する。数値一致だけで目視合格とはしない。

ユーザー確認用GIFはSceneViewの実装描画を650/650/500msで連続表示したもので、実ゲーム録画ではない。Idle・休養・筋トレ・仕事・掃除の全対象でユーザー見た目受入済み。v5ではBASE/SH足元を6倍拡大して確認し、他の合格済み対象は出力PNG比較で保持した。v5の実ゲーム端末検証は未実施。
